# @north-foundry/ui

Shared UI components for North Foundry frontends.

- [AlertDialog](src/components/alert-dialog/) — Confirmation dialogs for actions that need an explicit decision.
- [Badge](src/components/badge/) — Compact labels for status, categories and counts.
- [Button](src/components/button/) — Controls for actions and navigation.
- [Checkbox](src/components/checkbox/) — Controls for toggling individual options and showing partial selections.
- [DitherUnderlay](src/components/dither-underlay/) — Decorative dithered textures and gradients.
- [Icon](src/components/icon/) — Lucide glyphs at the theme's size steps.
- [Input](src/components/input/) — Single-line text entry.
- [Label](src/components/label/) — Accessible labels for form controls.
- [NorthArrow](src/components/north-arrow/) — The North Foundry brand mark.
- [RadioGroup](src/components/radio-group/) — Controls for choosing one option from a visible set.
- [Select](src/components/select/) — A menu for choosing one option from a list.
- [Switch](src/components/switch/) — Controls for turning settings on or off.
- [Textarea](src/components/textarea/) — Multiline text entry.
