# Project instructions

This is the single project instruction entry point. Use `.agents/docs/` as the
source of conventions; read applicable documents before editing:

- `.agents/docs/language.md` — English-only policy for all repository content,
  including code, documentation and project communication, with its stated
  exceptions.
- `.agents/docs/commits.md` — commit message format and workflow.

When changing `.agents/docs/`, check that this index's paths and descriptions
match all documents present; index only documents inside `.agents/`. Other
changes do not require an index review.

Apply these conventions rather than introducing competing ones.
