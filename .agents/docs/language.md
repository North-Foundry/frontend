# Language

All written content in this repository must be in English.

This applies to:

- source code: identifiers, comments, docstrings, log and error messages
- documentation: README files, AGENTS.md, files under `.agents/`, comments and descriptions in configuration files
- Git history and review: commit messages, branch names, pull request titles and descriptions, code review comments
- project communication: issues, task descriptions, and messages written on behalf of this repository

Product copy shown to end users stays in English as well, unless a specific localization requirement states otherwise.

If a request, source, or external document is written in another language, translate the substance into English rather than copying the original wording.

The only exceptions are files that must keep a fixed non-English value to work, such as an Italian shipping address inside a test fixture or an exact quoted string asserted by a test. Document such an exception next to the value when it is not obvious.
